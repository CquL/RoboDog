## SDK Introduction

The unitree_sdk2 is the SDK developed by Unitree Robotics for its next-generation robots. The SDK encapsulates interfaces such as low-level motor control and high-level motion control, and provides corresponding function interfaces. You can follow the provided interfaces and examples, along with the *H2 SDK Development Guide*, to learn robot control and carry out secondary development of the H2 robot.
