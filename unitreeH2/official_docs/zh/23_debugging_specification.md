您可以使用自己的 PC（**Ubuntu系统**）通过网线连接 H2 机身肩部的以太网口，来建立 User PC 和 H2 之间的通讯。您的程序既可以部署再自己 PC 上，也可以部署在 H2 自带的二次开发板上，通过 DDS 网络控制 H2 运动。 

**Step 1**:将 H2 固定在保护支架上，确保支架底部四个万向轮锁死。
![](https://doc-cdn.unitree.com/static/2026/3/18/9e209aa8def9451dbc172b9f3effc682_821x1269.png)


**Step 2**: User PC 通过以太网线，跟设备的RJ45口连接, 详见[《关于H2》](https://support.unitree.com/home/zh/H2_developer/About_H2)章节中的的电气接口介绍，即可进行通信调试。

!!! note
在当前系统版本下，一旦 H2 开机，内置的运动控制程序会自动启动，即使您没有操作遥控器。该程序会定期发送速度为 0 的指令。然而，如果您在这种状态下使用 SDK 进行底层开发，可能会导致指令冲突，从而使 H2 出现抖动的情况。

因此，在需要使用 SDK 进行开发调试时，请务必确保 H2 已经进入调试模式，以停止运动控制程序发送指令，这样可以避免潜在的指令冲突问题。您可以按下 L2 + A 来确认是否进入了调试模式。

如果按下 L2 + A 后行为与教学视频不相符，可多次长按按 L2 + R2，确保进入调试模式。
!!!
