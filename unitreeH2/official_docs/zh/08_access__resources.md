## SDK 介绍
unitree_sdk2 是宇树科技为新一代机器人开发的 SDK。SDK 将底层电机控制、高层运动控制等接口进行封装，并提供相关的函数接口。您可以按照我们提供的接口和例程，配套 《H2 SDK 开发指南》，学习机器人控制，完成 H2 的二次开发。
