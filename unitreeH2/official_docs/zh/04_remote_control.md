# 概念说明


<table>
<tr>
<th bgcolor="#D3D3D3"  style="width: 10%;">概念</th>
<th bgcolor="#D3D3D3">说明</th>
</tr>
  <tr>
    <td> 零力矩模式 </td>
    <td> 机器人所有电机停止主动运动，摆动时没有阻尼感。</td>
  </tr>
<tr>
<td >阻尼模式</td>
<td> 机器人所有电机停止主动运动，摆动时有明显阻尼感，可以进入预备模式 </td>
</tr>
  <tr>
<td >预备模式</td>
<td> 机器人将在5秒内缓慢摆出运动模式前的准备姿势（无平衡控制） </td>
</tr>
  <tr>
<td >运动模式</td>
<td> 可以通过遥控器控制机器人移动的模式 </td>
</tr>
  <tr>
<td >持续走路模式</td>
<td> 机器人始终处于踏步状态 </td>
</tr>
  <tr>
<td >站立模式</td>
<td> 该模式下，当摇杆指令为零时，机器人停止踏步，进入站立；当摇杆指令不为零，或机器人受到干扰难以维持平衡时，机器人将开始迈步。 </td>
</tr>
  <tr>
<td >调试模式</td>
<td> 用于底层开发。在需要使用 SDK 进行开发调试时，请务必确保 H2 已经进入调试模式(阻尼或零力矩模式下，遥控器按L2+R2进入调试模式)，以停止运动控制程序发送指令，这样可以避免潜在的指令冲突问题。您可以按下 L2+A 来确认是否进入了调试模式。调试中，若出现紧急情况，请通过遥控器按 L2 + B 让设备进入阻尼状态。 </td>
</table>

> 机器人行走模式，暂未部署爬楼梯的功能，请勿随意爬楼梯，避免损伤机器人。
