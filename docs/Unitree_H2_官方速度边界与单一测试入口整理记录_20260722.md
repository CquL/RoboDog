## 官方资料核对结果

宇树 H2 官方产品页：

`https://www.unitree.com/cn/H2/`

当前公开参数表没有列出 H2 最高行走速度。

H2 官方 RPC 文档只给出以下示例：

```bash
./h2_loco_client --network_interface=enp3s0 \
  --set_velocity="0.5 0 0 1"
```

它证明 `vx=0.5 m/s、duration=1 s` 是官方示例值，但没有说明这是最大值。

固定 SDK2 版本的 `LocoClient::SetVelocity(float vx, float vy, float omega, float duration)` 只把四个参数序列化并调用 API 7105，没有数值范围检查或范围注释。官方示例程序也只检查参数数量为 3 或 4，不检查数值范围。

因此不能把任何当前数值称为“H2 官方最大速度”。项目中的：

```cpp
vx       = 0.50
vy       = 0.10
omega    = 0.30
duration = 0.30
```

都是项目审核后的安全包络，不是宇树公布上限。其中只有前向 `vx=0.50 m/s` 已同时得到官方示例和本台交付 H2 实机验证；其余轴及 duration 是项目保守值，仍需后续标定。

## 三个 YAML 开关的含义

以下字段不是宇树 SDK 参数，是 RoboDog `UnitreeH2` 适配器增加的安全门禁：

| 字段 | 含义 | 导航速度控制建议 |
|---|---|---|
| `allow_motion_commands` | 是否允许非零速度到达 `SetVelocity` | `true` |
| `allow_state_changing_actions` | 是否允许 `Start/Damp/StandUp/Squat/Sit` | `false` |
| `verify_fsm_on_init` | 初始化时是否读取并验证 FSM | `true` |
| `required_motion_fsm_id` | 非零速度要求的 FSM | `601` |

`allow_state_changing_actions=false` 不影响 `stop_move`；停止命令仍然允许执行。只有将来确实由代码承担状态切换、并完成独立实机验收时，才考虑开启状态动作。

唯一程序支持互斥模式：

```text
--read-only
--getter-audit
--zero-stop --execute
--velocity --vx ... --vy ... --omega ... --duration-ms ... --execute
--action <name> --execute
```

速度模式完整走：

```text
RobotFactory
-> shared_ptr<RobotHardwareInterface>
-> initRobotHardware()
-> writeRobotVelocityCommand()
-> UnitreeH2
-> LocoClient::SetVelocity()
```

程序不再修改 YAML；若安全配置禁止运动，或请求值会被配置限幅，程序在建立 DDS 控制通道前明确拒绝。
