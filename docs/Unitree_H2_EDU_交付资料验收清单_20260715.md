# Unitree H2 EDU 交付资料验收清单

公开官网和 SDK 不能替代随设备交付的安全/运维资料。采购或验收时向宇树或代理商逐项
索取并确认版本：

## 型号与二次开发权限

- 合同/铭牌明确为 **H2 EDU**，不是只写 H2；
- 二次开发计算单元的实际配置：PC2、PC3、PC4、内存、存储、GPU；
- SDK、固件、运动控制服务和机器人序列号的兼容矩阵；
- 开源、内部使用、再分发和商用许可边界。

## 安全与运维

- 用户手册、安全手册、遥控器按键表、急停/解急停流程；
- 关节限位、速度/负载/工作空间限制、防跌倒和吊装要求；
- 开关机、充电、电池存储、故障码和日志导出说明；
- 系统恢复镜像、校验值、恢复工具和出厂分区说明。

## 开发接口

- 完整 SDK2/IDL、网络拓扑、默认 IP、DDS domain、QoS 和端口；
- 高层运动动作/FSM 状态机及每个动作的前置条件、返回码和超时语义；
- `LowState`/BMS/secondary IMU/odom 的字段、单位、频率、时间戳和 CRC；
- 低层 `LowCmd` 调试模式、内置控制器停启与冲突处理（本阶段不启用）；
- 双目相机/雷达的型号、接口、驱动、内外参、畸变、坐标系和硬件同步方式；
- 灵巧手及其他选配件的独立 SDK 和功耗/控制限制。

## Docker 与部署

- 计算单元 CPU 架构是 amd64 还是 arm64；
- Ubuntu、内核、NVIDIA 驱动、CUDA、ROS 2 和 CycloneDDS 版本；
- 容器是否允许 host network、共享内存、GPU、设备节点和实时调度；
- 原厂服务的 systemd/容器进程清单，以及哪些服务禁止停止。

收到的私有资料应保存到受控位置，并记录来源、版本、日期、SHA-256 和访问权限；未经
许可不提交到公开仓库或对外分发。
