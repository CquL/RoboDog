# X30 45 度楼梯厂商技术咨询问题清单

更新时间：2026-07-14  
咨询对象：云深处 X30 技术支持/二次开发支持

## 1. 项目目标

我们正在对 X30 Pro 进行二次开发，计划在感知主机上运行一个 ROS2 Humble Docker，
由容器直接接收四台 MID360 和本体 IMU，并运行自研定位、建图和导航算法。

普通行走、L 行走和山地步态已经能够通过厂家 UDP 指令切换。当前需要确认：当原厂
ROS1 Livox/IMU 接收节点停止后，如何由 ROS2 Docker 正确提供 45 度楼梯步态所需的
局部地形/落脚数据，同时保持厂家运动主机的安全状态机和失效保护。

## 2. 我们现场观察到的原厂链路

以下是现场只读观察结果，希望以厂家正式说明为准：

```text
/livox/lidar + /imu/data + /leg_odom + TF
  -> /deeprobotics_local_height_map_mid360/height_map
  -> /plane_seg
  -> /plane_seg/quadrangels (sensor_msgs/PointCloud2, frame_id=world, 约 10 Hz)
  -> /gridmap_port
  -> TCP 192.168.1.103:49999
  -> 运动主机地形/落脚控制
```

我们同步记录了 ROS 消息和 TCP 流，观察到 `gridmap_port` 基本将
`/plane_seg/quadrangels` 中的 XYZ 点封装后发送到运动主机。正常数据按每四点一组
形成一个地形四边形，但每帧第 0 组存在退化点，尚不清楚其官方语义。

接口规格书中，我们理解 45 度楼梯需要先准备累积帧地形模式，再切换楼梯步态并等待
对应状态确认。请厂家确认该理解和完整流程。

## 3. 希望厂家确认的问题

### 3.1 官方支持方式

1. X30 是否提供面向第三方算法的 ROS2、C++ SDK 或独立 API，用于生成并发送楼梯地形/落脚数据？
2. 是否有 x86_64 + ROS2 Humble 可用的 `local_height_map`、`plane_seg` 或 `gridmap_port` 版本？
3. 是否允许第三方程序直接向运动主机 `192.168.1.103:49999` 提供等价格式的数据？该接口是否属于正式对外接口？
4. 能否提供该接口的协议文档、示例代码、测试接收器或标准样例数据？

### 3.2 输入数据和处理链

1. 45 度楼梯步态必须使用哪些传感器：四台 MID360、本体 IMU、腿部里程计、激光里程计和 TF 是否缺一不可？
2. 可以使用第三方 ROS2 LIO 和局部高度图吗，还是必须使用原厂 LIO/高度图模块？
3. 原厂局部高度图输入、地图尺寸、分辨率、坐标系、重力对齐和运动补偿的正式要求是什么？
4. 原厂地形处理是否必须持续运行，还是只在进入楼梯模式前后运行？

### 3.3 `/plane_seg/quadrangels` 语义

1. 是否确认每四个 XYZ 点表示一个支撑面四边形？
2. 四个顶点的顺序是顺时针还是逆时针，起点如何定义？
3. 每帧第 0 个退化四点组表示什么：参考姿态、无效标记、边界还是其他控制信息？
4. 坐标系是否必须为 `world`，单位是否为米，原点和轴方向如何定义？
5. 四边形表示完整台阶顶面、可见平面，还是已经筛选后的可落脚区域？
6. 对平面坡度、面积、台阶高度、台阶深度和置信度有哪些过滤要求？

### 3.4 `103:49999` 传输协议

1. 该端口正式使用 TCP 还是存在不同软件版本使用 UDP 的情况？
2. 请提供帧头、长度、点数据、时间戳、序号、结束标记及大小端定义。
3. 是否需要握手、心跳、确认应答、重连或单发送者限制？
4. 推荐发送频率是多少，允许的抖动和最大延迟是多少？
5. 地形数据中断多久后会失效，运动主机收到陈旧数据时会停止、降级还是继续执行？

### 3.5 45 度楼梯状态机

1. 请确认进入 45 度楼梯步态前的完整命令顺序、目标端口、指令码和应答值。
2. `height_map_mode`、`height_map_mode_state`、`robot_basic_state` 和 `robot_gait_state` 的正式枚举及转换条件是什么？
3. 累积帧模式从准备状态进入就绪状态的判定条件是什么？
4. 楼梯步态退出、异常恢复和恢复普通行走的推荐流程是什么？
5. 在地形数据丢失、LIO 漂移、状态超时或通信断开时，运动主机是否自动停止？

### 3.6 安全约束

1. 累积帧楼梯模式是否确实不提供地形碰撞检测？
2. 第三方导航需要承担哪些避障、限速、急停和数据新鲜度检查？
3. 45 度楼梯步态允许的前进/后退速度上限是多少？
4. 官方支持的楼梯高度、深度、宽度、坡度及机器人起始距离范围是什么？
5. 是否有不发送运动速度的地形接口验收方法，可先验证地图数据是否被运动主机正确接收？
