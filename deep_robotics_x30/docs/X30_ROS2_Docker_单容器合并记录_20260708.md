## 1. 本次准备做什么

当前 X30 ROS2 传感器链路之前拆成了多个容器：

```text
x30_livox_ros2   接收四个 MID360 雷达，发布 /livox/lidar 和 /livox/imu
x30_cloud_merger 合并点云，发布 /x30/points_merged
x30_body_imu     接收本体 Yesense IMU，发布 /x30/body_imu
```

这在调试阶段方便，但后续我们希望在机器狗上只启动一个 ROS2 Docker：

```text
一个镜像
一个容器
同时接收雷达、雷达 IMU、本体 IMU
同时发布合并点云
后续继续在这个 ROS2 环境里接入自研算法模块
```

目标容器：

```text
镜像：x30_livox_ros2:jezetek
容器：x30_ros2_sensors
启动：ros2 launch x30_livox_tools x30_all_sensors_launch.py
```

## 2. 单容器内部节点规划

单容器内启动三个 ROS2 节点：

```text
x30_livox_ros2
  输入：四个 MID360 UDP 数据
  输出：/livox/lidar, /livox/imu

time_window_cloud_merger
  输入：/livox/lidar
  输出：/x30/points_merged

x30_body_imu
  输入：/dev/ttyS0 Yesense 本体 IMU
  输出：/x30/body_imu, /x30/body_imu_raw
```

对外关键话题：

| 话题 | 类型 | 说明 |
|---|---|---|
| `/livox/lidar` | `sensor_msgs/msg/PointCloud2` | 四雷达原始点云 |
| `/livox/imu` | `sensor_msgs/msg/Imu` | MID360 内置 IMU |
| `/x30/points_merged` | `sensor_msgs/msg/PointCloud2` | 100 ms 窗口合并点云 |
| `/x30/body_imu` | `sensor_msgs/msg/Imu` | 机器狗本体 Yesense IMU |

## 4. 上机测试命令

从本地打包并传输：

```powershell
cd D:\Desktop\RoboDog
tar -czf x30_livox_ros2_transfer.tar.gz x30_livox_ros2_transfer
scp .\x30_livox_ros2_transfer.tar.gz ysc@192.168.1.106:/home/ysc/
```

注意：下面命令必须在机器狗宿主机 shell 中执行，提示符应该类似：

```text
ysc@ysc-perception:...$
```

如果提示符是：

```text
root@ysc-perception:/ws#
```

说明还在 Docker 容器内部，需要先执行：

```bash
exit
```

在机器狗 `192.168.1.106` 宿主机上解压并构建：

```bash
cd /home/ysc
mv x30_livox_ros2_transfer x30_livox_ros2_transfer.bak_$(date +%Y%m%d_%H%M%S) 2>/dev/null || true
tar -xzf x30_livox_ros2_transfer.tar.gz
cd x30_livox_ros2_transfer
chmod +x remote/*.sh
bash remote/00_build_image.sh
```

启动单容器前，先关闭会占用硬件资源的原厂 ROS1 驱动：

```bash
bash remote/02_factory_livox_off.sh
bash remote/11_factory_imu_off.sh
```

启动单容器：

```bash
bash remote/18_run_ros2_all.sh
```

检查只剩一个 X30 ROS2 传感器容器：

```bash
docker ps --format 'table {{.Names}}\t{{.Image}}\t{{.Status}}\t{{.Command}}'
```

期望看到：

```text
x30_ros2_sensors   x30_livox_ros2:jezetek   Up ...
```

检查 ROS2 话题：

```bash
bash remote/19_check_ros2_all.sh
```

也可以手动进入容器：

```bash
docker exec -it x30_ros2_sensors bash
source /opt/ros/humble/setup.bash
source /ws/install/setup.bash
ros2 topic list
```

期望至少看到：

```text
/livox/lidar
/livox/imu
/x30/points_merged
/x30/body_imu
```
