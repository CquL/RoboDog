日期：2026-07-30

## 目标

生产 Docker 只承担：

1. 接收 105 只读转发的点云、IMU 和里程计。
2. 安装 X30 `RobotHardwareInterface` HAL。
3. 为后续 ROS2 导航控制节点提供统一输入和底层控制库。

105 原厂 ROS1 继续独占传感器并运行原厂 LIO、地形图、`plane_seg`
和 `gridmap_port` 链路。
