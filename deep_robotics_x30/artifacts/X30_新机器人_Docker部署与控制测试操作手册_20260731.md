```bash

sha256sum -c x30_sensor_forwarder_105.tar.gz.sha256

tar -xzf x30_sensor_forwarder_105.tar.gz
```

## 4. 106 导入镜像并创建 Docker

```bash
ssh ysc@192.168.1.106
cd /home/ysc

sed -i 's/\r$//' x30_livox_ros2_jezetek_amd64.tar.sha256
sed -i 's/\r$//' x30_livox_ros2_transfer.tar.gz.sha256
sha256sum -c x30_livox_ros2_jezetek_amd64.tar.sha256
sha256sum -c x30_livox_ros2_transfer.tar.gz.sha256

docker load -i x30_livox_ros2_jezetek_amd64.tar
tar -xzf x30_livox_ros2_transfer.tar.gz

cd /home/ysc/x30_livox_ros2_transfer
chmod +x remote/*.sh

grep -qE '^192\.168\.1\.105[[:space:]]+ysc([[:space:]]|$)' /etc/hosts ||
  echo '192.168.1.105 ysc' | sudo tee -a /etc/hosts

export ROS_MASTER_URI=http://192.168.1.105:11311
export ROS_IP=192.168.1.106
unset ROS_HOSTNAME

bash remote/26_run_passive_relay.sh
bash remote/28_status_passive_relay.sh
```

```text
网络：host
```

```bash
  --once /x30/lidar_points --field header

  --once /x30/body_imu --field header

  --once /x30/leg_odom --field header
```

## 7. Docker 内最小控制命令

```bash
T=/opt/x30_robot_hardware/bin/robot_test_x30
C=/opt/x30_robot_hardware/share/robot_hardware/config/config.yaml

# 说明，不发送 UDP
$T $C list

# 零速度
$T $C zero

# 步态
$T $C gait walk
$T $C gait l_walk
$T $C gait mountain
$T $C gait stairs

# 前进 0.30 m/s，5 秒
$T $C move 0.30 0 0 5 CONFIRM_MOVE

# 左转/右转
$T $C move 0 0 0.30 3 CONFIRM_MOVE
$T $C move 0 0 -0.30 3 CONFIRM_MOVE
```

当前为 `udp_navigation`。发送非零速度前确认原厂导航速度源已选中、场地清空、
遥控急停可用。速度结束后只归零速度，不自动改变步态。

## 8. 机器人关机重启后的恢复

目前 105 转发器和 `x30_ros2_passive` 没有系统自启动。重启后不需要重新导入
镜像或重新编译，只按以下顺序启动。

先确认 105 原厂数据已经恢复：

```bash
# 105
source /opt/ros/noetic/setup.bash
source /home/ysc/jy_cog/drivers/setup.bash 2>/dev/null || true
source /home/ysc/jy_cog/system/devel/setup.bash 2>/dev/null || true

timeout 5 rostopic echo --noarr -n 1 /lidar_points
timeout 5 rostopic echo --noarr -n 1 /imu/data
timeout 5 rostopic echo --noarr -n 1 /leg_odom
```

在 106 恢复容器：

```bash
# 106
sudo systemctl start docker
cd /home/ysc/x30_livox_ros2_transfer

export ROS_MASTER_URI=http://192.168.1.105:11311
export ROS_IP=192.168.1.106
unset ROS_HOSTNAME

bash remote/26_run_passive_relay.sh
```

在 105 恢复转发器：

```bash
# 105
cd /home/ysc/x30_sensor_forwarder_105
bash remote/02_start_forwarder_105.sh
```

回到 106 验证并进入 Docker：

```bash
# 106
cd /home/ysc/x30_livox_ros2_transfer
bash remote/27_check_passive_relay.sh

docker exec -it x30_ros2_passive bash --norc
source /opt/ros/humble/setup.bash
source /ws/install/setup.bash
ros2 topic list | grep '^/x30/'
```

## 9. 日常状态、进入和停止

查看容器：

```bash
docker ps --filter name=x30_ros2_passive
```

容器正在运行时直接进入：

```bash
docker exec -it x30_ros2_passive bash --norc
```

停止本项目：

```bash
# 105
cd /home/ysc/x30_sensor_forwarder_105
bash remote/04_stop_forwarder_105.sh

# 106
cd /home/ysc/x30_livox_ros2_transfer
bash remote/29_stop_passive_relay.sh
```

这些脚本只操作本项目转发器和容器，不停止 105 原厂 ROS1 节点。
